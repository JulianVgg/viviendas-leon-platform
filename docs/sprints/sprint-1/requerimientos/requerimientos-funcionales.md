# Requerimientos funcionales

## 1. Familias y beneficiarios

| ID | Requerimiento |
|---|---|
| RF-001 | El sistema deberá permitir registrar familias beneficiarias. |
| RF-002 | El sistema deberá permitir registrar los integrantes asociados a una familia. |
| RF-003 | El sistema deberá permitir actualizar la información de las familias y sus integrantes. |
| RF-004 | El sistema deberá permitir asociar una familia con una comunidad. |
| RF-005 | El sistema deberá permitir asociar una familia con uno o más programas institucionales. |
| RF-006 | El sistema deberá permitir gestionar el estado de una familia como activa, retirada o egresada. |
| RF-007 | El sistema deberá permitir consultar el historial de actividades asociadas a una familia. |

## 2. Gestión agrícola

| ID | Requerimiento |
|---|---|
| RF-008 | El sistema deberá permitir registrar y administrar huertos asociados a las familias. |
| RF-009 | El sistema deberá permitir registrar cultivos asociados a los huertos. |
| RF-010 | El sistema deberá permitir registrar fechas de siembra o trasplante y cantidades establecidas. |
| RF-011 | El sistema deberá permitir registrar la producción agrícola. |
| RF-012 | El sistema deberá permitir registrar las unidades de medida utilizadas para la producción. |
| RF-013 | El sistema deberá permitir registrar información relacionada con ventas e ingresos aproximados. |
| RF-014 | El sistema deberá permitir registrar plagas y enfermedades identificadas en los cultivos. |
| RF-015 | El sistema deberá permitir registrar porcentajes de daño y tratamientos aplicados. |
| RF-016 | El sistema deberá permitir registrar los insumos agrícolas entregados a las familias. |
| RF-017 | El sistema deberá permitir consultar el historial agrícola de una familia. |

## 3. Visitas, asistencia técnica y capacitaciones

| ID | Requerimiento |
|---|---|
| RF-018 | El sistema deberá permitir planificar visitas de campo. |
| RF-019 | El sistema deberá permitir asignar una visita a una familia y a un trabajador responsable. |
| RF-020 | El sistema deberá permitir registrar los resultados de una visita de campo. |
| RF-021 | El sistema deberá permitir registrar evaluaciones de los huertos durante las visitas. |
| RF-022 | El sistema deberá permitir registrar recomendaciones derivadas de una asistencia técnica. |
| RF-023 | El sistema deberá permitir registrar fechas de seguimiento de las recomendaciones. |
| RF-024 | El sistema deberá permitir registrar capacitaciones realizadas. |
| RF-025 | El sistema deberá permitir registrar el tema, fecha, facilitador y participantes de una capacitación. |

## 4. Funcionamiento sin conexión y sincronización

| ID | Requerimiento |
|---|---|
| RF-026 | El sistema deberá permitir registrar información de campo cuando el dispositivo no tenga conexión a Internet. |
| RF-027 | El sistema deberá almacenar temporalmente los registros realizados sin conexión en el dispositivo. |
| RF-028 | El sistema deberá identificar los registros pendientes de sincronización. |
| RF-029 | El sistema deberá sincronizar los registros pendientes cuando se restablezca la conexión. |
| RF-030 | El sistema deberá actualizar el estado de los registros después de una sincronización exitosa. |

## 5. Reportes, indicadores y alertas

| ID | Requerimiento |
|---|---|
| RF-031 | El sistema deberá permitir generar reportes de la información registrada. |
| RF-032 | El sistema deberá permitir filtrar información de los reportes por diferentes criterios. |
| RF-033 | El sistema deberá presentar indicadores relacionados con los programas institucionales. |
| RF-034 | El sistema deberá presentar indicadores de familias atendidas y huertos activos. |
| RF-035 | El sistema deberá presentar indicadores relacionados con producción, visitas, plagas e insumos. |
| RF-036 | El sistema deberá generar alertas relacionadas con actividades pendientes. |
| RF-037 | El sistema deberá identificar registros incompletos que requieran atención. |
| RF-038 | El sistema deberá permitir exportar información en formato Excel. |
| RF-039 | El sistema deberá permitir generar reportes en formato PDF. |
| RF-040 | El sistema deberá permitir comparar información correspondiente a diferentes periodos. |

## 6. Usuarios, roles, permisos y auditoría

| ID | Requerimiento |
|---|---|
| RF-041 | El sistema deberá permitir crear usuarios. |
| RF-042 | El sistema deberá permitir actualizar usuarios. |
| RF-043 | El sistema deberá permitir desactivar usuarios. |
| RF-044 | El sistema deberá permitir asignar roles a los usuarios. |
| RF-045 | El sistema deberá controlar el acceso a las funcionalidades según los permisos del usuario. |
| RF-046 | El sistema deberá permitir iniciar y cerrar sesión. |
| RF-047 | El sistema deberá registrar las operaciones relevantes realizadas por los usuarios. |
| RF-048 | El sistema deberá permitir consultar la bitácora de operaciones. |
| RF-049 | El sistema deberá permitir filtrar los registros de auditoría por usuario, fecha y tipo de operación. |

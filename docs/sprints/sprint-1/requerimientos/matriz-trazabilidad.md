# Matriz de trazabilidad de requerimientos

Esta matriz relaciona los requerimientos definidos con los elementos del alcance aprobado del proyecto. El módulo de voluntariado queda fuera del alcance de esta versión de los requerimientos.

## 1. Trazabilidad por alcance

| Elemento del alcance | Requerimientos funcionales | Requerimientos no funcionales |
|---|---|---|
| Familias y beneficiarios | RF-001 a RF-007 | RNF-017 a RNF-020 |
| Gestión agrícola | RF-008 a RF-017 | RNF-017 a RNF-020 |
| Visitas, asistencia técnica y capacitaciones | RF-018 a RF-025 | RNF-006 a RNF-016 |
| Funcionamiento offline | RF-026 a RF-030 | RNF-010, RNF-012, RNF-014 a RNF-016, RNF-020 |
| Monitoreo, reportes, indicadores y alertas | RF-031 a RF-040 | RNF-010, RNF-011, RNF-017 |
| Administración y seguridad | RF-041 a RF-049 | RNF-001 a RNF-005 |
| Usabilidad | — | RNF-006 a RNF-009 |
| Rendimiento | — | RNF-010 a RNF-012 |
| Conectividad irregular | RF-026 a RF-030 | RNF-013 a RNF-016 |
| Integridad y consistencia | — | RNF-017 a RNF-020 |
| Mantenibilidad y documentación | — | RNF-021 a RNF-023 |

## 2. Roles contemplados

Los requerimientos de administración y control de acceso contemplan los roles definidos para el proyecto:

- Trabajador de campo
- Coordinación
- Dirección operativa
- Administración
- Auditoría

## 3. Exclusión de alcance

El módulo de voluntariado no forma parte del alcance actual de esta especificación. Por esta razón, no se incluyen requerimientos funcionales ni no funcionales específicos para dicho módulo.

## 4. Criterios de cobertura

La especificación cubre los elementos establecidos en el issue:

- Requerimientos funcionales documentados.
- Requerimientos no funcionales documentados.
- Identificador único para cada requerimiento.
- Descripción clara de cada requerimiento.
- Correspondencia entre los requerimientos y el alcance aprobado.
- Seguridad contemplada.
- Funcionamiento offline contemplado.
- Conectividad irregular contemplada.

> **Nota:** La relación de cada requisito con los issues específicos del repositorio se completará cuando se revise el listado definitivo de issues del proyecto.
